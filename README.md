
# MoneyTrack - 存款管理

MoneyTrack存款管理一是款专门用为户打造的财务理管工具，帮助您时实追踪存款变化，轻松理管多个账户，让你的财状务况一目了然。为了避免获取过多感敏权限，本软件采用动手填充的方式获存取款数据。

## ✨ 核心功能

### 🏦 多账户管理
- **账户分类**：支持储蓄账户、支付宝、微信钱包等多种账户类型
- **实时统计**：自动计算所有账户的总存款金额
- **账户操作**：支持添加、编辑、删除账户操作

### 💰 智能金额管理
- **存入/取出**：支持对指定账户进行存款和取款操作
- **余额验证**：取款时自动检查账户余额是否充足
- **金额调整**：可随时调整账户余额

### 📊 可视化分析
- **趋势图表**：直观展示存款变化趋势
- **时间筛选**：支持查看最近7天、1个月、3个月或全部历史数据
- **动态图表**：自适应屏幕尺寸的响应式图表

### 📈 历史记录
- **操作记录**：自动记录每次金额变动的历史
- **记录管理**：支持编辑和删除历史记录
- **时间排序**：按日期降序排列，最新记录显示在最上方

### 📱 数据导出
- **CSV格式**：支持导出所有记录为CSV格式
- **数据复制**：一键复制导出数据到剪贴板
- **完整备份**：包含账户信息和历史记录

## 🚀 快速开始

### 环境要求
- Node.js (推荐最新LTS版本)
- HBuilderX (uni-app开发工具)

### 安装步骤
1. 克隆或下载项目到本地
2. 使用HBuilderX打开项目
3. 连接真机或使用模拟器运行

### 运行项目
```bash
# 在HBuilderX中选择运行到指定平台
# 或使用命令行工具
npm run dev:%PLATFORM%
```

### 打包发布
```bash
# 打包为指定平台的应用
npm run build:%PLATFORM%
```

## 核心功能实现

### 数据存储
应用使用uni-app的本地存储API实现数据持久化：
```javascript
// 保存数据
uni.setStorageSync('accounts', this.accounts);
uni.setStorageSync('moneyHistory', this.moneyHistory);

// 加载数据
const savedAccounts = uni.getStorageSync('accounts');
const savedMoneyHistory = uni.getStorageSync('moneyHistory');
```

### 图表绘制
使用Canvas API实现动态图表：
- 自适应屏幕尺寸
- 智能刻度计算
- 数据点连线
- 日期标签防重叠

### 响应式设计
- 适配不同屏幕尺寸
- 移动端友好界面
